# DAY 17: Git & GitHub Notes

## Git vs GitHub
- Git → version control tool (tracks changes)
- GitHub → website to store and share code

## Key Commands (for future reference)
- git init → initialize repo
- git add . → stage all changes
- git commit -m "message" → save changes
- git push → upload to GitHub
- git pull → download from GitHub
- git clone → copy a repo
- git branch → create/view branches
- git merge → combine branches

## Key Concepts
- Repository → project folder
- Commit → save point
- Branch → separate version
- Pull Request → request to merge branches
- Fork → copy someone's repo
- Clone → download a repo
